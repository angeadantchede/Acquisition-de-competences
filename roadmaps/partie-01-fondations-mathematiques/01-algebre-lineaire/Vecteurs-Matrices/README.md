# Vecteurs et matrices

Première série d’exercices du Chapitre 1 — Algèbre linéaire.

Travail finalisé : opérations sur vecteurs et matrices, à la main puis en Python / NumPy.

## Contenu

| Fichier | Niveau | Sujet |
| --- | --- | --- |
| [`exo1.py`](./exo1.py) | Débutant | Somme, produit scalaire, normes de vecteurs |
| [`exo2.py`](./exo2.py) | Débutant | Transposée et dimensions d’une matrice |
| [`exo3.py`](./exo3.py) | Intermédiaire | Produit matrice × vecteur — vérif NumPy (`@` / `dot`) |
| [`exo4.py`](./exo4.py) | Intermédiaire | Deuxième produit matrice × vecteur — vérif NumPy |
| [`exo5.py`](./exo5.py) | Avancé | Multiplication de matrices **sans NumPy** (listes + boucles) |
| [`exo6.py`](./exo6.py) | Avancé | Perf. 200×200 : implémentation maison vs NumPy |

## Ce qui a été travaillé

- Calculs manuels (énoncés dans les docstrings / commentaires)
- Vérification des produits avec NumPy
- Implémentation from scratch de la multiplication matricielle
- Comparaison de performances et réflexion sur la vitesse de NumPy
- Note personnelle dans `exo5` : patience face à la difficulté, apprentissage par la pratique

## Lancer un exercice

cd roadmaps/partie-01-fondations-mathematiques/01-algebre-lineaire/Vecteurs-Matrices
