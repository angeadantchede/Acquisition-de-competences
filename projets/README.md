# Projets

Projets réalisés dans le cadre de mon acquisition de compétences.

Chaque projet vit dans son propre sous-dossier, avec un `README.md` qui explique :

- le problème traité ;
- la stack utilisée ;
- comment lancer le projet ;
- ce qui a été appris.

## Conventions

```text
projets/
└── nom-du-projet/
    ├── README.md
    ├── src/           # ou app/, notebooks/, selon le type
    ├── docs/          # optionnel
    └── requirements.txt / pyproject.toml / package.json
```

- Pas de secrets, pas de datasets bruts volumineux.
- Un projet est publié quand il est présentable (README + code lisible).
